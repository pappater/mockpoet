# சிறிய விளக்கும் பெருங்காரிருளும் (A Small Lamp in Deep Night)

> "நெடும் இருள் தனக்குத்தானே அஞ்சுவதில்லை; ஓர் அகல் விளக்கின் நடுங்கும் சுடருக்கே அஞ்சுகிறது."

பெரிய மாற்றங்கள் எப்போதும் ஆரவாரத்தோடு தொடங்குவதில்லை. இருண்ட அறையின் மூலையில் ஏற்றப்படும் ஒரு சிறிய சுடர் போதும்—நம்பிக்கை எவ்வளவு மென்மையானதோ, அவ்வளவு அசைக்க முடியாததும் கூட.
